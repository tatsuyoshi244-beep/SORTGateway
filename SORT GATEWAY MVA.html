🔒 セキュリティと接続

Anthropic API キーはサーバーの .env のみに保持します。ここでは接続確認のみ行います。

起動: cd server && node index.js
アクセス: http://127.0.0.1:3001（file:// では開かないでください）

🔧 回答挙動の設定

SORTの回答スタイルを細かく制御できます。
参照ドキュメントを表示
回答の根拠となったドキュメント名を表示します
「情報なし」の場合に正直に伝える
ドキュメントに情報がない場合、推測せず明示します
日本語で回答を強制
質問が英語でも必ず日本語で回答します
簡潔モード
回答を箇条書き・短文で返します
